# Product Overview and Instructions

## Product Overview

Select from Meals is a database-driven meal-tracking web application designed to help users organize the foods they eat and monitor their daily nutritional intake. User can record food items under breakfast, lunch, dinner or snacks and view nutritional information such as calories, protein, carbohydrates and fat.
The application addresses the difficulty of keeping information in different places, users can store their meals in one system and view their information through a simple dashboard.
The application uses MySQL relational database containing 4 connected tables: users, foods, meals and meal items. These relationships allow the systems to associate each meal with a user and each food item with a specific meal. The database also stores the quantity of each food so that nutritional totals can be calculated based on the amount consumed.

## Main Features
- stores user information
- organize meals as breakfast, lunch, dinner or snacks
- add food items and quantities to meals
- track calories, protein, carbohydrates and fat
- view recorded meals and nutritional totals
- create, view, edit and delete meal records
- display nutrition information through dashboard

## User Instructions

1. start Select From Meals application and open it in a browser
2. create or select a user account 
3. choose date and meal type, such as breakfast, lunch, dinner or snack
4. search for or select food item
5. enter quantity of food consumed in grams
6. add food item to the selected meal
7. open dashboard to view meal and its calorie and macronutrient totals
8. use available options to edit or delete an existing meal when necessary
